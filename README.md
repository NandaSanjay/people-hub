# 🧑‍💼 PeopleHub

A modern HR dashboard application built with Angular (Standalone Components) featuring employee management, dashboard analytics, filtering, and clean enterprise UI.

---

## 🚀 Features

### ✅ Core Features
- Employee List (Directory view)
- Employee Detail page with tabs (Profile / Job / Compensation)
- Add Employee form
- Pagination

---

### 📊 Dashboard Features
- Total Employees widget
- Department count
- Average salary calculation
- Active employees

---

### 🔍 Filtering & Search
- Real-time search (name, email, department)
- Department filter dropdown
- Combined filtering + pagination

---

### 🧭 Navigation & UX
- Sidebar layout (enterprise style)
- Breadcrumb navigation with dynamic employee names
- Responsive layout

---

### 🎨 UI Enhancements
- Dashboard widgets with icons (Font Awesome)
- Empty state UI (no data)
- Hover effects and transitions

---

## 🛠️ Tech Stack

- Angular (Standalone Components)
- TypeScript
- HTML / CSS
- Font Awesome (icons)
- RxJS
